Scenario 1: Legal Document Review Agent System

Question:
What kind of agent design pattern fits best, and how would failure handling be incorporated?

| **Field**    | **Details**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Project**  | Multi-Agent Legal Document Review System                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Problem**  | Reviewing legal documents manually is slow, error-prone, and may overlook risky clauses or inconsistent legal language.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Cause**    | A single AI agent cannot efficiently handle clause extraction, risk analysis, and revision generation while ensuring accuracy and reliability.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Solution** | - Use a **Sequential Pipeline (Multi-Agent Workflow)** design pattern.<br>- **Clause Extractor Agent** extracts key legal clauses (confidentiality, termination, indemnity, liability, payment, etc.).<br>- **Risk Detection Agent** analyzes extracted clauses and flags risky or non-standard terms with severity levels.<br>- **Revision Suggestion Agent** recommends safer wording and improved legal clauses.<br>- Validate the output of each agent before passing it to the next stage.<br>- Implement **automatic retries** for temporary failures (e.g., API or model errors).<br>- Use **fallback mechanisms**, such as rule-based checks or Human-in-the-Loop (HITL), if an agent fails or confidence is low.<br>- Log all agent outputs, errors, and decisions for auditing, debugging, and compliance. |

Scenario 2: Agentic Code Review Platform

Scenario:
You built an agentic code review platform. Users upload code, and agents offer improvements. But feedback isn’t always aligned between agents.

Question:
How do you handle conflicting feedback in a Multi-Agent Review workflow?

| **Field**    | **Details**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Project**  | Multi-Agent Code Review Platform                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Problem**  | Different review agents provide conflicting suggestions, making it difficult for developers to determine the best improvement.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Cause**    | Each agent specializes in a different aspect of the code (e.g., code quality, security, performance, and coding standards), resulting in contradictory recommendations.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Solution** | - Use a **Multi-Agent Review with Consensus** design pattern.<br>- Assign specialized agents such as **Code Quality Agent**, **Security Agent**, **Performance Agent**, and **Style Agent**.<br>- Introduce a **Coordinator/Orchestrator Agent** to collect, compare, and consolidate feedback from all agents.<br>- Prioritize recommendations using predefined rules (e.g., **Security > Correctness > Performance > Style**).<br>- Resolve conflicts using a **Consensus/Voting Mechanism** or confidence scoring.<br>- Escalate unresolved or low-confidence conflicts to a **Human-in-the-Loop (HITL)** reviewer for final approval.<br>- Log all agent feedback, conflicts, and final decisions to improve future review accuracy and consistency. |
