Scenario 1: Legal Document Review Agent System

Question:
What kind of agent design pattern fits best, and how would failure handling be incorporated?

| **Field**    | **Details**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Project**  | Multi-Agent Legal Document Review System                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Problem**  | Reviewing legal documents manually is slow, error-prone, and may overlook risky clauses or inconsistent legal language.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Cause**    | A single AI agent cannot efficiently handle clause extraction, risk analysis, and revision generation while ensuring accuracy and reliability.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Solution** | - Use a **Sequential Pipeline (Multi-Agent Workflow)** design pattern.<br>- **Clause Extractor Agent** extracts key legal clauses (confidentiality, termination, indemnity, liability, payment, etc.).<br>- **Risk Detection Agent** analyzes extracted clauses and flags risky or non-standard terms with severity levels.<br>- **Revision Suggestion Agent** recommends safer wording and improved legal clauses.<br>- Validate the output of each agent before passing it to the next stage.<br>- Implement **automatic retries** for temporary failures (e.g., API or model errors).<br>- Use **fallback mechanisms**, such as rule-based checks or Human-in-the-Loop (HITL), if an agent fails or confidence is low.<br>- Log all agent outputs, errors, and decisions for auditing, debugging, and compliance. |

Scenario 2: Agentic Code Review Platform

Scenario:
You built an agentic code review platform. Users upload code, and agents offer improvements. But feedback isn’t always aligned between agents.

Question:
How do you handle conflicting feedback in a Multi-Agent Review workflow?

| **Field**    | **Details**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Project**  | Multi-Agent Code Review Platform                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Problem**  | Different review agents provide conflicting suggestions, making it difficult for developers to determine the best improvement.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Cause**    | Each agent specializes in a different aspect of the code (e.g., code quality, security, performance, and coding standards), resulting in contradictory recommendations.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Solution** | - Use a **Multi-Agent Review with Consensus** design pattern.<br>- Assign specialized agents such as **Code Quality Agent**, **Security Agent**, **Performance Agent**, and **Style Agent**.<br>- Introduce a **Coordinator/Orchestrator Agent** to collect, compare, and consolidate feedback from all agents.<br>- Prioritize recommendations using predefined rules (e.g., **Security > Correctness > Performance > Style**).<br>- Resolve conflicts using a **Consensus/Voting Mechanism** or confidence scoring.<br>- Escalate unresolved or low-confidence conflicts to a **Human-in-the-Loop (HITL)** reviewer for final approval.<br>- Log all agent feedback, conflicts, and final decisions to improve future review accuracy and consistency. |

Scenario 3: Educational Tutoring System

Scenario:
In an educational tutoring system, an agent answers queries, but users often misunderstand explanations.

Question:
How can agent design help personalize and simplify responses for different learners?

| **Field**    | **Details**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Project**  | AI-Powered Educational Tutoring System                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Problem**  | Users often misunderstand the agent's explanations, resulting in poor learning outcomes and reduced engagement.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Cause**    | The agent provides the same explanation to all learners without considering their knowledge level, learning style, or preferred explanation format.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Solution** | - Use an **Adaptive Multi-Agent** design pattern with specialized agents.<br>- Implement a **Learner Profile Agent** to identify the learner's knowledge level, preferences, and learning style.<br>- Use a **Content Generation Agent** to create explanations tailored to beginner, intermediate, or advanced learners.<br>- Include a **Simplification Agent** to convert complex concepts into simple language, examples, analogies, or step-by-step explanations.<br>- Add a **Feedback Agent** to collect learner responses and identify areas of confusion.<br>- Continuously update the learner profile based on quiz results and interactions to improve future responses.<br>- Use Human-in-the-Loop (HITL) support for unresolved doubts or complex topics when necessary. |

Scenario 4: Nested Agent System for Legal Q&A

Scenario:
You built a Nested Agent system for legal Q&A, but agents sometimes give vague or incomplete answers.

Question:
How do you improve answer depth and reliability using Agentic Design?

| **Field**    | **Details**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Project**  | Nested Multi-Agent Legal Q&A System                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Problem**  | The agents sometimes generate vague, incomplete, or inconsistent legal answers, reducing user trust and answer quality.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Cause**    | The agents lack sufficient legal context, verification mechanisms, and quality checks before generating the final response.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Solution** | - Use a **Nested Agent Design Pattern** with specialized sub-agents.<br>- Implement a **Query Analysis Agent** to understand the user's legal question and identify the required legal domain.<br>- Use a **Retrieval Agent** with **RAG** to fetch relevant legal documents, regulations, and case laws from a trusted knowledge base.<br>- Add an **Answer Generation Agent** to create detailed, context-aware responses using the retrieved information.<br>- Include a **Fact Verification/Validation Agent** to verify legal references, citations, and answer accuracy before presenting the final response.<br>- Introduce a **Review/Coordinator Agent** to evaluate completeness, confidence score, and consistency across all agent outputs.<br>- Escalate low-confidence or complex legal queries to a **Human-in-the-Loop (HITL)** legal expert when necessary.<br>- Continuously update the legal knowledge base and maintain detailed logs for auditing, traceability, and continuous improvement. |
